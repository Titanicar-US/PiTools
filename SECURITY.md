# Security policy

PiTools handles GitHub App private keys, webhook secrets, installation tokens, and optional model-provider credentials. Do not include any of those values in issues, pull requests, logs, fixtures, or test output.

Report a suspected vulnerability privately to the repository maintainers. Do not open a public issue containing exploit details or credentials. Include the affected version, deployment profile, reproducible impact, and a safe contact method.

PiTools never merges pull requests. Human approval, GitHub branch protection, and infrastructure ownership remain outside the application.
